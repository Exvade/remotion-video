## 4. Tone of Voice

### Prinsip Utama
- **Santai & gaul** — pakai "lo-gue", bahasa sehari-hari
- **Edukatif** — ngasih value, bukan cuma jualan
- **Relatable** — pakai contoh yang UMKM bisa relate
- **Confident** — tau apa yang diomongin, tapi gak sombong
- **Semi-selling** — soft CTA, bukan hard sell

### ✅ Do's
- "Bisnis lo udah pake website belum?"
- "Tau gak? 70% customer cek website dulu sebelum beli."
- "Mau tau caranya? DM aja, konsultasi gratis."
- "Ini 3 alasan kenapa bisnis lo butuh website..."

### ❌ Don'ts
- "Kami menyediakan jasa pembuatan website terbaik..." (terlalu formal)
- "BELI SEKARANG! DISKON 50%!" (too salesy)
- "Hubungi kami segera untuk mendapatkan..." (boring corporate)
- Jangan pake emoji berlebihan (max 2-3 per slide)

## 5. Content Format

### Platform Specs
| Platform | Resolusi | Aspect Ratio | Durasi Ideal |
|---|---|---|---|
| **Instagram Reels** (utama) | 1080×1920 | 9:16 | 15-30 detik |
| Instagram Feed | 1080×1080 | 1:1 | - |
| IG Story | 1080×1920 | 9:16 | 15 detik/slide |

### Video Specs
| Setting | Value |
|---|---|
| **FPS** | 30 |
| **Codec** | H.264 |
| **Format** | MP4 |

### Content Formula: E.S.C (Educate → Seed → CTA)
1. **Hook** (2-3 detik) — Pertanyaan / fakta yang bikin stop scroll
2. **Educate** (10-15 detik) — Value, tips, perbandingan
3. **Seed** (3 detik) — Sisipkan bahwa Danova Digital bisa bantu
4. **CTA** (3-4 detik) — Soft CTA: DM, link di bio, konsultasi gratis

## 6. Illustration Style Guide

### Style
- **2D Flat Illustration** — clean, modern, minimal detail
- Referensi: Notion, Slack, Google illustration style
- **Outline:** Tidak ada outline / stroke, full fill shapes
- **Shadow:** Minimal, hanya soft shadow kalau perlu depth

### Karakter
- Flat character dengan bentuk simpel
- Kepala: lingkaran
- Badan: rounded rectangle
- Tangan/kaki: bentuk simpel
- Ekspresi: minimal tapi ekspresif (dot eyes, simple mouth)
- **Warna baju** pakai brand color (Danova Blue)
- Mood variations: thinking 🤔, sad 😔, happy 😄, presenting 👆

### Kapan Pakai Karakter vs Icon
| Konten | Gunakan |
|---|---|
| Hook / pembukaan | Karakter (lebih engaging) |
| Bullet points / list | Icon |
| Perbandingan | Karakter + Icon |
| Stat / angka | Icon atau tanpa ilustrasi |
| CTA | Logo saja |

### Background
- Selalu dark background (`#0D1117` atau gradient)
- Floating geometric shapes (subtle, opacity 10-20%)
- Shapes: circles, rounded squares, dots
- Warna shapes: brand colors dengan low opacity

## 7. Layout Rules

### Safe Zone
```
┌──────────────────────────────┐
│  40px padding semua sisi     │
│  ┌────────────────────────┐  │
│  │                        │  │
│  │     Content Area       │  │
│  │     (1000 × 1760)      │  │
│  │                        │  │
│  └────────────────────────┘  │
│                              │
│  Bottom: Logo + slide number │
└──────────────────────────────┘
```

### Alignment
- Teks: **center** untuk hook, **left** untuk bullet points
- Ilustrasi: **center** di atas atau samping teks
- Logo watermark: **bottom center**, opacity 50%, size kecil

## 8. Animation Guidelines

### Prinsip Animasi
- **Smooth & clean** — jangan terlalu bouncy atau flashy
- **Purposeful** — setiap animasi punya alasan
- **Consistent timing** — spring config yang sama di semua komponen

### Standard Animations
| Element | Animasi | Durasi |
|---|---|---|
| Teks masuk | Fade in + slide up | 15 frames |
| Bullet point | Slide in dari kiri + fade | 12 frames, stagger 8 |
| Karakter | Scale in + slight bounce | 20 frames |
| Background shapes | Slow float / drift | Continuous |
| Stat number | Count up + scale | 20 frames |
| Slide transition | Fade through dark | 15 frames |

### Spring Config (Remotion)
```ts
// Standard spring untuk semua animasi
{
  damping: 15,
  stiffness: 120,
  mass: 0.8,
}
```
